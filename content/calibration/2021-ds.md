## Question 6

 Venue treats classes like joinder. Under 1391(b)(2), we still must find a key event
common to all claims to lay venue. This is like mass joinder, where the number of claims
limits the scope of 1391(b)(2), if harm is distributed widely. Also Bristol-Myers-Squibbs
if it applied to class-actions.

 Ben-Hur treats class as unique entities. Holding that diversity for class actions is
limited to named plaintiffs implies that the class is somehow distinct from joinder, where
every single claimant would be relevant to calculating Strawbridge diversity. This is
unique, class-specific doctrine.

 Post Bristol-Myers-Squibb, it’s ambiguous whether class actions will be their own

legal entity or mass-joinders for IPJ. BMS, not a class action case, implies courts can’t
exercise IPJ over defendant as to some plaintiffs’ claims lacking International Shoe
contacts just because other plaintiffs’ claims have said IPJ. This forces us to analyze
class actions claim by claim like joinders.

 I prefer class actions as independent legal entities. Practically, they behave too
differently; we can’t say a mass class action is “the same” as ten thousand lawyers in a
room. The idea of thousands of claims, each of which wouldn’t occur in court

independently even if joinder were way easier, seems more akin to a large trust as noted
in class. Though federal courts are unfriendly to class actions, it would be artificial to call
